## Features

- Switches between npm, pnpm, yarn, and bun with a single click.
- Active package manager icon updates in real time.
- Lightweight command colorizer — no syntax highlighter dependency.
- One-click copy button on every command.
- Fully controlled via a `commands` prop — no magic string templates.

## Usage

```tsx
import { PackageManagerTabs } from '@/components/ui/package-manager-tabs';

<PackageManagerTabs
  commands={{
    npm: 'npx shadcn@latest add @lalit/copy-button',
    pnpm: 'pnpm dlx shadcn@latest add @lalit/copy-button',
    yarn: 'npx shadcn@latest add @lalit/copy-button',
    bun: 'bunx shadcn@latest add @lalit/copy-button',
  }}
/>
```
